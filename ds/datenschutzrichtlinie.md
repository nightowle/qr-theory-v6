## 2. Zweck der Datenverarbeitung

Diese GPT-Action stellt Funktionen zur Verfügung, um GitHub-Repositories automatisiert zu verwalten, darunter:

- Verwalten von SSH-Deploy-Keys  
- Auslösen und Überwachen von GitHub Actions Workflows  
- Erstellen, Bearbeiten und Löschen von Repository-Dateien  
- Veröffentlichen von Releases und Hochladen von Assets  
- Erstellen von Issues und Branches  

Die Verarbeitung erfolgt ausschließlich zur Durchführung der vom Benutzer initiierten API-Aktionen über GitHub.

---

## 3. Erhobene Daten

Folgende Daten werden im Rahmen der Nutzung verarbeitet:

- **GitHub OAuth Access Token** (temporär)  
- Repository-Metadaten (z. B. Name, Branches, Issues, Deploy Keys, Releases)  
- Informationen zum authentifizierten GitHub-Nutzer (z. B. Benutzername, E-Mail)

**Wichtig:**  
Es erfolgt keine dauerhafte Speicherung personenbezogener Daten auf unseren Servern.  
Die Tokens werden nur temporär für autorisierte API-Aufrufe verwendet.

---

## 4. Speicherung und Löschung

Diese GPT-Action speichert **keine Daten dauerhaft**.  
Daten wie GitHub Tokens oder Nutzerinformationen werden nur **flüchtig** verarbeitet und nach Erfüllung der Aktion sofort verworfen.  

Es erfolgt keine persistente Speicherung auf Datenbanken, Servern oder Logs.

---

## 5. Weitergabe an Dritte

**Nein.**  
Es erfolgt **keine Weitergabe** von personenbezogenen Daten an Dritte.  

Alle API-Aufrufe werden direkt von der Action zur GitHub API (https://api.github.com) gesendet.
